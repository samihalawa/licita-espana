# Licita España — Marketplace positioning

**Positioning:** Spanish public tenders with checkable deadlines, documented sources and a clear bid/no-bid preparation workflow.

**English subtitle:** Qualify public tenders

**Spanish subtitle:** Licitaciones con criterio

**中文简介:** 西班牙公共采购招标检索与资格要求核查。

**Description:** Search Spanish public tender notices, retain official tender IDs, budgets and dates, and identify which bid requirements need review in the source documents. This is a read-only workflow and does not submit offers.

**Starter prompts:**

1. Find Spanish software tenders and explain the deadline and search coverage.
2. Review these PCAP and PPT documents; quote the requirements that decide eligibility.
3. Show a documented sample and distinguish the saved example from current information.

**Model invocation boundaries:** Use for public procurement research, not for signing or filing bids. Recent feed updates do not prove a tender is open. Full document examination is needed to determine requirements. Preserve official record links and lot-specific differences.

**Claude Code:** Install this skills plugin from its public repository.

**ChatGPT MCP App:** Interactive UI requires a separately deployed public MCP endpoint and registered UI resource, not only a Claude manifest.

**Validation:** Test direct, indirect, out-of-scope, malformed-input and source-outage scenarios. Measure tool-selection precision and user task completion, not keyword density.
