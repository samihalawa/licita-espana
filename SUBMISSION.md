## Listing and runtime

Encuentra licitaciones y convierte sus pliegos en una decisión documentada: requisitos, plazos y próximos pasos.

Audience: Autónomos, pymes y consultoras que preparan ofertas públicas.

One declared local stdio MCP process provides the scoped adapters, historical demo and deterministic report text. Python 3.11+ is required; there are no third-party runtime dependencies, account credentials, hidden hooks, shell launchers or remote executables. No publisher-hosted MCP endpoint is claimed.

## Reviewer walkthrough

Install the exact candidate marketplace and verify the declared server appears. Call `licita_espana_demo` and inspect its dated historical marker. Call `licita_espana_report` with the demo operation and `format: html`; it returns escaped portable text, with no file write or external assets. Exercise the domain operation `licita_triage` only with an authorized official-source query and inspect dates, coverage, provenance and partial errors.
